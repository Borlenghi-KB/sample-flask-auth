## 📚 Projeto

O **sample-flask-auth** é um projeto desenvolvido com Python e Flask para colocar em prática conceitos relacionados à criação de uma **API de autenticação com banco de dados**.

O projeto foi desenvolvido como parte dos estudos realizados no curso de **Python da Rocketseat**, servindo como uma aplicação prática dos conteúdos apresentados durante o curso.

Entre os principais conceitos trabalhados estão:

- Criação de APIs com Flask
- Autenticação de usuários
- Integração com banco de dados
- Estruturação de aplicações Python
- Desenvolvimento de rotas
- Manipulação de dados
- Organização de um projeto backend

## 🎯 Objetivo

O principal objetivo deste projeto é aplicar, na prática, conhecimentos de **Python e desenvolvimento backend**, utilizando o Flask para construir uma API capaz de trabalhar com autenticação e persistência de dados.

Este projeto representa uma das etapas da minha trajetória de aprendizado em desenvolvimento de software, contribuindo para a construção de conhecimentos em **Python, APIs, bancos de dados e desenvolvimento backend**.
